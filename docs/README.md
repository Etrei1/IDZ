ИДЗ по ТиМП 
Группировка логов с автоматическим созданием вложенных структур через defaultdict 

# Задание
Системный администратор имеет большой файл логов. Каждая строка содержит:
```
дату, имя сервера, уровень сообщения (INFO, WARNING, ERROR) и само сообщение
```

Необходимо организовать данные для быстрого доступа к сообщениям по серверу и уровню. Для этого создайте структуру на основе `defaultdict`, где
```
ключ первого уровня — имя сервера,значение — ещё один defaultdict(list), в котором ключ второго уровня — уровень сообщения, а значение — список сообщений
```

**Задачи:**
1. Выведите все сообщения уровня ERROR для сервера "web01".
2. Для каждого сервера подсчитайте количество сообщений каждого уровня (используйте Counter или просто длину списка).
3. Найдите сервер, у которого наибольшее количество WARNING-сообщений.
4. Добавьте новое сообщение в структуру и убедитесь, что автоматически создаются нужные вложенные словари.

**Цель:**
Использовать `defaultdict` для построения многоуровневых структур без лишних проверок.
